# Changelog

## 2.1.0.0

- Reworked the DINKFLIX frontend into a desktop-first browsing experience instead of a CSS-only skin.
- Added custom navigation and route handling.
- Added Recently Added hero rotation with pause-on-hover/focus.
- Added Continue Watching, Recently Played, Recently Added, Movies, TV Shows and My List sections.
- Added dedicated Movies and TV Shows library grids with search, sorting and filters.
- Added custom title detail pages with ratings, genres, tags, technical badges and My List.
- Added a DINKFLIX About page and project story.
- Removed runtime dependencies on external fonts and frontend frameworks.
- Added reduced-motion support and a lighter visual effects model.
- Updated GitHub Actions to Node 24-capable action releases and an Ubuntu 24.04 runner.
- Made release creation idempotent so an existing tag/release can be updated instead of failing.
- Added Jellyfin 12.1 ABI metadata and validation workflow.
