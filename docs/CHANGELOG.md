# DINKFLIX v2 changelog

## 2.0.0-foundation — September 2026

- Replaced the old ElegantFin-oriented architecture with a DINKFLIX-owned frontend layer.
- Added floating desktop navigation.
- Added recently-added API-driven hero.
- Added lazy hero image loading and pause-aware rotation.
- Added DINKFLIX homepage rows for Continue Watching, Recently Added, Movies, TV Shows and My List.
- Added DINKFLIX card metadata and hover presentation.
- Added Jellyfin-favourite-backed My List.
- Added detail-page My List action.
- Added DINKFLIX About route.
- Added reduced-motion support.
- Removed dependency on Home Screen Sections for the core homepage experience.
