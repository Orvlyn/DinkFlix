DINKFLIX Web

DINKFLIX is a desktop-first Jellyfin Web experience designed to make your server feel like a polished streaming service without replacing Jellyfin's playback engine.

Frontend
Injected directly by the DINKFLIX plugin. JavaScript Injector is not required for DINKFLIX.
Jellyfin compatibility
Built for Jellyfin 12.1 Web and uses the current web client session for API access.

Your existing File Transformation, Jellyfin Enhanced, Intro Skipper and other plugins can remain installed. DINKFLIX does not require Home Screen Sections.
