DINKFLIX Web

Version 4.2.0 · a desktop-first Jellyfin Web experience.

Frontend
DINKFLIX injects its CSS and JavaScript directly into Jellyfin Web through File Transformation. No Custom CSS import is required.
Navigation
DINKFLIX discovers your Jellyfin libraries and creates navigation entries automatically. Movies and TV use Jellyfin's normal hash routes; extra libraries use a DINKFLIX view route.
Plugins
Keep File Transformation, Jellyfin Enhanced and Intro Skipper. JavaScript Injector can remain installed for unrelated scripts. Avoid a second home-screen replacement plugin while DINKFLIX is active.
