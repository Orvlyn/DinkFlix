DINKFLIX Web owns the desktop Jellyfin Web experience. It uses Jellyfin's existing APIs and File Transformation to serve the frontend without modifying Jellyfin Web on disk.

Prerequisites

Jellyfin 12.1.x and File Transformation 3.0.1.x are required.

Installed features

Clean navigation, recently-added hero, Continue Watching, Recently Played, Recently Added, Movies, TV Shows, My List, ratings and quality badges, detail-page actions, and a DINKFLIX About page.

Other plugins

JavaScript Injector is not required for DINKFLIX itself. Keep it for unrelated custom scripts. Jellyfin Enhanced, Intro Skipper and Seerr may coexist; Kefin Tweaks should be tested separately if it changes the same header or home DOM.
