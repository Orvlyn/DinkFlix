DINKFLIX Web

Desktop streaming, redesigned.

DINKFLIX is a desktop-first Jellyfin Web experience built for easy browsing, recently added discovery, rich title information and a simple My List.

DINKFLIX Web is installed.

The redesigned web interface is injected by File Transformation. After installing or updating DINKFLIX, refresh the browser with Ctrl+Shift+R.

Compatibility

DINKFLIX Web targets Jellyfin 12.x desktop Web. File Transformation is required. Jellyfin Enhanced, Intro Skipper and other plugins can remain installed; DINKFLIX does not require Home Screen Sections.

For troubleshooting, check the Jellyfin log for DINKFLIX Web File Transformation registered successfully.
