DINKFLIX Web is installed
Version 3.0.0. The desktop Jellyfin Web experience is supplied by this plugin.
Frontend injection
DINKFLIX registers with File Transformation and embeds its own CSS and JavaScript into Jellyfin Web. No Custom CSS import is required.
Recommended plugin setup
Keep File Transformation, Jellyfin Enhanced and Intro Skipper. Keep JavaScript Injector for other scripts, but do not inject DINKFLIX there as well.
