# DINKFLIX Web

DINKFLIX Web is a regular Jellyfin plugin for the desktop Jellyfin Web experience. It adds a custom DINKFLIX shell, navigation, hero, discovery rows, libraries, My List, search, title pages and lightweight native-page styling.

DINKFLIX itself does not require JavaScript Injector, Custom CSS or Home Screen Sections. File Transformation may remain installed for other plugins.

Built for Jellyfin 12.1 / .NET 10.
