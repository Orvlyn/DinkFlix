DINKFLIX Web 3.0 — ONE-TIME GITHUB UPLOAD

1. Extract this ZIP.
2. Open your DinkFlix GitHub repository.
3. Click Add file -> Upload files.
4. Upload all visible files/folders from this extracted package. Do NOT upload the ZIP itself.
5. Commit the changes.
6. GitHub may omit the hidden .github folder. That is expected.
7. Click Add file -> Create new file.
8. File name: .github/workflows/dinkflix-release.yml
9. Open GITHUB-WORKFLOW.txt from this package, copy ALL of its contents, paste them into GitHub, and commit.
10. Go to Actions -> DINKFLIX Build & Release -> Run workflow.
11. Leave the version as 3.0.0.0 and click Run workflow.
12. Wait for the build to finish GREEN.
13. In Jellyfin add:
    Name: DINKFLIX
    URL: https://raw.githubusercontent.com/Orvlyn/DinkFlix/main/manifest.json
14. Install DINKFLIX Web and restart Jellyfin.

DO NOT paste dinkflix.css into Jellyfin Custom CSS after the plugin is installed.
DO NOT paste dinkflix.js into JavaScript Injector after the plugin is installed.
DO NOT upload another ZIP over this repository.
