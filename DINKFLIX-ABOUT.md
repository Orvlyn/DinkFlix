# DINKFLIX

DINKFLIX is a custom Jellyfin theme and UI enhancement plugin maintained by **Orvlyn**.

It gives Jellyfin a dark, cinematic, spacious streaming-service presentation while keeping Jellyfin responsible for your media library, authentication, playback, administration and native routes.

## Using DINKFLIX

1. Install and enable **File Transformation**.
2. Add the DINKFLIX manifest in **Dashboard → Plugins → Repositories**:
   https://raw.githubusercontent.com/Orvlyn/DinkFlix/main/manifest.json
3. Install DINKFLIX from the Jellyfin plugin catalog.
4. Restart Jellyfin.
5. Configure it from **Dashboard → Plugins → DINKFLIX**.
6. Refresh the Jellyfin web client.
