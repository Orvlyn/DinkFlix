# DINKFLIX

DINKFLIX is a personal, evolving Jellyfin visual project built from the SleekFin foundation.

## What this project is

- A DINKFLIX-branded visual layer for Jellyfin.
- A dark, spacious interface direction with the DINKFLIX mint accent: `#00ffc6`.
- An incremental redesign intended to preserve Jellyfin's native navigation, playback, authentication, administration, and plugin functionality wherever possible.

## Credits

**Original foundation:** SleekFin by its original author and contributors. Please see the upstream SleekFin project and its license for the original work and attribution requirements.

**DINKFLIX modifications:** branding, visual direction, mint theme overrides, and future project-specific improvements by Orvlyn.

This is an ongoing development project, not a claim that every Jellyfin version or plugin combination has been fully tested. Changes should be validated against the target Jellyfin installation before being treated as production-ready.
